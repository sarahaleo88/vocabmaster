# VocabMaster — Full Design Summary

## Overview

A personal English vocabulary flashcard app for Android, built with web technologies (HTML/CSS/JS) and packaged as an APK using Capacitor. Features spaced repetition (SM-2), offline-first storage, and 800 built-in vocabulary words.

**Target User:** Chinese native speaker learning English, also studying programming.

---

## Tech Stack

| Layer | Technology |
|-------|------------|
| UI | Vanilla HTML/CSS/JS |

| Storage | IndexedDB (via idb library) |
| Settings | localStorage |

## Data Model

### Card Schema (IndexedDB)

```javascript
{
  id: string,              // UUID
  word: string,            // English word
  translation: string,     // Chinese translation
  example: string,         // Example sentence
  pronunciation: string,   // IPA notation
  tags: string[],          // ["general"] or ["programming"]
  
  // SM-2 fields
  easiness: number,        // Default 2.5, min 1.3
  interval: number,        // Days until next review
  repetitions: number,     // Successful reviews in a row
  nextReview: number,      // Timestamp
  
  // Metadata
  createdAt: number,
  isBuiltIn: boolean       // true = bundled, false = user-added
}
```

### Settings (localStorage)

```javascript
{
  newCardsPerDay: number,       // 5-50, default 20
  todayNewCardsCount: number,   // Reset daily
  lastReviewDate: string        // Track day changes
}
```

## SM-2 Spaced Repetition

### Rating Options

| Button | Score | Effect |
|--------|-------|--------|
| Again | 0 | Reset, review in 1 day |
| Hard | 1 | Shorter interval |
| Good | 2 | Normal progression |
| Easy | 3 | Longer interval |

### Algorithm

```
1. Update easiness factor (EF):
   EF = EF + (0.1 - (3 - rating) * (0.08 + (3 - rating) * 0.02))
   Minimum EF = 1.3

2. Calculate interval:
   - Rating < 2: reset to 1 day
   - First success: 1 day
   - Second success: 6 days
   - After: interval = previous * EF

3. Set nextReview = today + interval
```

### Daily Review Flow

1. Pull all due cards (`nextReview <= today`) — no limit
2. Add new cards up to daily limit (default 20)
3. Present in random order
4. Update SM-2 fields after each rating
5. "Again" cards re-enter today's queue

## Import/Export

### Import

| Feature | Implementation |
|---------|----------------|
| Formats | CSV and JSON |
| Column detection | Smart match common names, fallback to fixed order |
| Fixed order | `word, translation, example, pronunciation, tags` |
| Duplicates | Skip (safe default) |
| Preview | Show count + first 5 words before confirming |

### Export

| Option | Contents |
|--------|----------|
| Full Backup | All cards + SM-2 progress (JSON) |
| Word List Only | Core data only, no stats (JSON) — shareable |

## Error Handling

| Scenario | Response |
|----------|----------|
| Save failed | Toast: "Save failed, please try again" |
| Import parse error | Show failed rows, import valid ones |
| No cards due | "All caught up!" + next review date |
| Empty database | Prompt to import or add first card |
| Mid-session exit | Auto-save after each rating |
| Storage check | Display usage in Settings |
| Corrupted data | "Reset App" option in Settings |

## Build & Distribution

### Dev Environment Requirements

- Node.js 18+
- Android Studio (with SDK + Build Tools)
- Java JDK 17
- Environment: `ANDROID_HOME`, `platform-tools` in PATH

### Build Commands

```bash
npm install
npm run dev          # Local development
npm run build        # Production build
npx cap sync         # Sync to Android
npx cap open android # Open in Android Studio
# Build APK from Android Studio
```

### Distribution

- GitHub Releases: host signed APK
- GitHub Pages: landing page with download button + install guide
- README: screenshots, features, CSV format docs
